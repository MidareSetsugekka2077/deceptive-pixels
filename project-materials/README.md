# Project Materials

This folder preserves the original non-application project materials that were
packaged alongside the game source code.

Contents include:

- `data/`: evaluation data folder structure and data guidance.
- `presentation/`: presentation placeholder.
- `status_report/`: status report templates and exemplar.
- `src/adversarial-images/`: notebooks used to generate adversarial image sets.
- `plan.md`, `root-readme.md`, `src/readme.md`, and `src/manual.md`: original
  project template notes.

The runnable game application remains at the repository root.
